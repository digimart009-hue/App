# Muhammad Shazim Mahmood — Portfolio Website

A premium, modern, single-page portfolio website built to attract clients and present
professional work with style.

## ✨ Highlights

- **Elegant luxury theme** — deep navy + gold, inspired by a polished professional look
- **Animated loader** and smooth scroll-reveal animations
- **Typing effect** in the hero section
- **Animated stat counters**
- **Fully responsive** — looks great on mobile, tablet, and desktop
- **Sections:** Hero · About · Stats · Services · Portfolio · Testimonials · Contact
- **Portfolio button** links directly to the Google Drive folder
- **Working contact form** (opens the user's email client with the message pre-filled)
- **Scroll-to-top button** and sticky navbar with mobile menu

## 📁 Structure

```
.
├── index.html          # The full website (HTML + CSS + JS in one file)
├── assets/
│   └── shazim.png      # Profile photo
└── README.md
```

## 🚀 How to view

Just open `index.html` in any web browser — no build step or server required.

To put it online for free, you can use **GitHub Pages**, **Netlify**, or **Vercel**:
upload these files and the site is live.
